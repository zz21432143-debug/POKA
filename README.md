# 펠트클럽 (Felt Club)

포커 플레이어와 딜러를 위한 커뮤니티 웹사이트입니다.

PC와 모바일 브라우저(Android/iOS)에서 같은 반응형 웹으로 접속합니다.

## 현재 범위

1. **DB 모델** — 회원, 게시글, 댓글/출석, 레벨 경험치
2. **메인 레이아웃** — 좌/우 게시판 사이드바, 프로필 위젯, 모바일 햄버거 드로어, 프리미엄 배너 6구좌

인증·글쓰기·추천 처리는 이후 단계에서 붙입니다.

## 화면 구조

- **PC:** 왼쪽 사이드바(전체 게시판 + 하단 프로필), 가운데 본문, 오른쪽 사이드바(프로필 + 전체 게시판)
- **모바일:** 상단 고정 헤더에 햄버거와 요약 프로필(마크, 레벨, 닉네임). 게시판은 왼쪽 GNB 드로어
- **배너:** 데스크톱 6열, 태블릿 3열, 모바일 2×3. 터치 영역 최소 44px

게시판 메뉴: 자유, 핸드리뷰, 매장후기, 출석, 구인 3종(딜러/스태프/플레이어), 홍보.

1단계 스키마 확인은 `/schema` 입니다.

## 로컬 실행

Node.js 20+ 가 필요합니다.

```bash
cp .env.example .env
npm install
npx prisma migrate dev --name init
npx prisma db seed
npm run dev
```

개발 서버: `http://127.0.0.1:43123`

## 주요 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 (포트 43123) |
| `npm run db:migrate` | 마이그레이션 |
| `npm run db:seed` | 샘플 회원·게시글·레벨 표 |
| `npm run db:reset` | DB 초기화 후 시드 |

스키마 원본은 `prisma/schema.prisma` 입니다.

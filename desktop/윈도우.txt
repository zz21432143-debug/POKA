POKA를 Windows에서 열려면

1. POKA.bat / POKA.url 파일만 받아서 바탕화면에 두면 안 됩니다.
   사이트 프로그램이 그 안에 없어서 창이 깜빡이고 꺼지거나, 빈 브라우저만 뜹니다.

2. 프로젝트 폴더 전체에서 실행하세요.
   - Node.js 20 설치: https://nodejs.org
   - 폴더에서 npm install
   - desktop\POKA.bat 더블클릭 → 서버를 켜고 브라우저를 엽니다.
   - desktop\윈도우-바탕화면설치.bat → 바탕화면에 POKA.url (지구본 아이콘)을 만듭니다.

3. 다운로드한 .bat 이 안 열리면: 우클릭 → 속성 → 맨 아래 "차단 해제" 체크 → 확인.

4. Cursor 클라우드에서 보던 화면은 이 PC의 localhost 가 아닙니다.
   내 컴퓨터에서 쓰려면 위처럼 프로젝트를 이 PC에 두고 서버를 켜야 합니다.
